# 스고 항해일지

OPTC 스고 캐릭터의 보유 및 성장 현황을 기록하는 독립형 팬메이드 체크리스트입니다.

## 기능

- 초스고, 주년 스고, 해적제 스고, 트맵 스고, 유대 스고, 일반 스고 분류
- 보유, 무지개, 초무지개, 해적제한돌, 레벨상한돌파 기록
- 초진화 전 캐릭터 일괄 숨김과 개별 캐릭터 제거·복구
- 브라우저 자동 저장 및 JSON 저장파일 이동
- 1200px 고해상도 PNG 공유 이미지 생성
- 데스크톱·모바일 반응형 화면과 재접속 캐시

## 배포

이 폴더의 전체 파일을 새 GitHub 저장소 최상단에 올린 뒤 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.

로컬에서 확인할 때는 파일을 직접 여는 대신 간단한 웹 서버로 실행해야 `data/characters.json`을 정상적으로 읽을 수 있습니다.

## 권리 고지

이 프로젝트는 비공식 팬메이드 도구입니다. 게임명, 캐릭터, 캐릭터 이미지 등 게임 자료에 관한 권리는 각 권리자에게 있습니다. 이 저장소의 자체 제작 웹 코드에 대한 라이선스를 정하더라도 게임 이미지에는 적용되지 않습니다.

배포 전 캐릭터 이미지와 데이터의 사용 조건을 별도로 검토하세요.
