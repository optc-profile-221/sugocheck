SUGOCHECK 방문 통계 배포 순서

이 폴더의 Worker 소스는 공개해도 되지만 비밀값은 공개하면 안 됩니다.
VISITOR_HASH_SECRET과 ADMIN_TOKEN을 파일에 기록하거나 GitHub에 올리지 마세요.

1. Node.js 설치 후 이 폴더에서 Cloudflare Wrangler를 실행합니다.
   npx wrangler login

2. 현재 연결된 D1 데이터베이스는 Cloudflare 빠른 시작에서 만든 prod-d1-tutorial이며,
   database_id는 wrangler.toml에 이미 입력되어 있습니다.

3. 테이블을 생성합니다.
   npm run migrate

4. 충분히 긴 임의 문자열 두 개를 각각 비밀값으로 등록합니다.
   npx wrangler secret put VISITOR_HASH_SECRET
   npx wrangler secret put ADMIN_TOKEN

5. Worker를 배포합니다.
   npx wrangler deploy

6. 출력된 https://...workers.dev 주소를 메인 프로젝트의 index.html과
   festival-rare.html에 있는 sugocheck-metrics-endpoint meta content에 동일하게 입력합니다.
   이후 sw.js CACHE_NAME을 다음 버전으로 올립니다.

7. 브라우저에서 https://여기에_WORKER주소/admin 을 열고 ADMIN_TOKEN을 입력하면
   일일/누적 방문자와 국가·지역 통계를 확인할 수 있습니다. 관리자 페이지 링크는
   본 사이트에 표시되지 않으며 토큰 없이는 통계 데이터에 접근할 수 없습니다.

8. PowerShell 조회 예시:
   Invoke-RestMethod -Headers @{ Authorization = "Bearer 여기에_ADMIN_TOKEN" } `
     -Uri "https://여기에_WORKER주소/stats?days=30"

응답의 totals는 서비스 시작 이후 누적값이고 daily는 한국 시간 기준 날짜별 값입니다.
방문자 구분은 브라우저에서 만든 무작위 익명 ID를 사용합니다. 국가·광역 지역은
Cloudflare가 접속 IP로 판별한 값을 집계하지만 IP 원문과 도시 정보는 저장하지 않습니다.
